**Short description**

Create and clone Moodle courses with data validation, scheduling and per-course tracking.

**Full description**

SkillUps Course Factory creates and clones Moodle courses using native course and backup/restore APIs. Operators preview a single request or a CSV/XLSX batch, choose an institutional template, schedule provisioning and assign authorized staff. Course results include failures, recoverable stages and cancellation status. Community operates on the Moodle installation. This listing is prepared for submission. [Marketplace submission workflow](https://docs.moodle.org/503/en/Plugins_FAQ#How_do_I_submit_my_own_plugin_to_Moodle_Marketplace?)
