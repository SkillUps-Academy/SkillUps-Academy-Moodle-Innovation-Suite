# Registro de cambios

## 0.9.0-beta.1

- Panel operativo bilingüe para Moodle y su base de datos con estado nativo de cron, tareas y componentes.
- Historial de disponibilidad interna con cobertura, mantenimiento, percentil de latencia y resumen CSV.
- Gestión de incidentes y alertas mediante tareas programadas, auditoría y confirmación humana de revisión.
- Diagnóstico con permisos nativos, dos rutas HTTPS opcionales y ejemplos de Prometheus y Grafana.
