SkillUps System Monitor gives Moodle site operators an operational dashboard, cron and task diagnostics, authorized error metadata, incident history, notifications and availability reporting with explicit coverage. Community operates locally. Optional HTTPS endpoints support external collection and independent probing. The system context privacy provider covers notification destinations and incident review attribution.

Community functions, installation guidance, screenshots and the test matrix are in the [plugin documentation](../README.md) and [validation report](validation.md). A signed annual entitlement enables detailed timeline CSV exports. Submission status is draft.
