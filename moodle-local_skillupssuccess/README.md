# SkillUps Student Success Predictor

Seguimiento académico en Moodle con reglas explicables, un modelo estadístico opcional y un flujo humano de casos. Registra señales de acceso, entregas individuales, notas y actividad. Permite asignar tutores, documentar intervenciones y evaluar resultados con cohortes prospectivas.

- Componente `local_skillupssuccess` · Plugin local · SkillUps Academy Moodle Innovation Suite
- Inglés y español · GPL-3.0-or-later
- Community funciona sin SkillUps Cloud.
