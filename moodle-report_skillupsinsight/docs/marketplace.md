## Short English description

Compare Moodle academic periods with scoped institutional dashboards, reusable reports, and indicator targets.

## Full English description

SkillUps Insight Analytics uses Moodle enrolment capabilities, the standard log store, the gradebook and course completion to publish aggregate academic snapshots. Authorized managers can compare periods, group by category, program or course, save personal reports and download CSV, XLSX or PDF. Recurring Moodle notifications link to saved reports and indicator targets. The dashboard distinguishes recorded actions from time spent and documents the source and coverage of each metric.
