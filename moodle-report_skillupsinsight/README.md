# SkillUps Insight Analytics

Plataforma de analítica institucional para Moodle. Usa períodos académicos, capturas de indicadores y filtros por categoría, programa y curso. El constructor guarda columnas y filtros privados. Los informes se exportan a CSV, XLSX y PDF. Las metas y alertas usan notificaciones internas de Moodle.

- Componente `report_skillupsinsight` · Tipo report · SkillUps Moodle Innovation Suite
- Inglés y español · GPL-3.0-or-later
- Community funciona sin SkillUps Cloud.
