# Contribuciones

Instala el plugin en `report/skillupsinsight` de una instancia descartable de Moodle. Ejecuta `vendor/bin/phpunit --testsuite report_skillupsinsight_testsuite` y los escenarios Behat con la etiqueta `@report_skillupsinsight`. Usa el estándar Moodle CodeSniffer y revisa la paridad EN/ES. Toda fórmula nueva debe documentar su unidad, fuente, población y comportamiento con datos ausentes.
