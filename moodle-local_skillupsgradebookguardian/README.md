# SkillUps Gradebook Guardian

**`local_skillupsgradebookguardian`** · Plugin local de Moodle · GPL-3.0-or-later

Audita la configuración del libro de calificaciones por curso y relaciona elementos, actividades, categorías y dependencias. Guarda diagnósticos comparables, muestra recomendaciones y permite aprobar o recuperar un ajuste de visibilidad con simulación previa.

## English

A course-level diagnostic and approval tool for Moodle Gradebook. Install the ZIP through **Site administration → Plugins → Install plugins** and open **SkillUps Gradebook Guardian** from the course navigation. Community includes the full diagnosis, comparisons, assisted visibility repair, recovery and CSV export. Optional signed entitlements enable JSON export. No external service or additional library is required.
