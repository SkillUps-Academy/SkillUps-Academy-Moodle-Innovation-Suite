# Moodle Marketplace submission draft

- **Plugin name** — SkillUps Gradebook Guardian
- **Component** — `local_skillupsgradebookguardian`
- **Release** — `0.9.0-beta.1`, beta
- **License** — GPL-3.0-or-later

- **Short description** — Diagnose course gradebook configuration and review or approve a reversible visibility correction with a course-scoped audit trail.

- **Full description** — Gradebook Guardian reviews categories, aggregation, weights, hidden items, formulas and activity relationships. Compare saved diagnoses, inspect structural dependencies and export reports. An authorized manager can hide an eligible grade item for an already hidden activity and restore the original visibility after a separate approval. It uses the native Gradebook API and does not submit learner grades. Optional signed entitlements add JSON export, and the Community workflow works offline.

The SkillUps Academy suite is independently maintained. This package requires Moodle without any separate Composer installation. It bundles no third-party libraries. English strings are canonical. The direct installation archive includes Spanish localization. Check the current translation and source-layout rules during submission. The companion [validation](validation.md) records tested versions and screenshots.
