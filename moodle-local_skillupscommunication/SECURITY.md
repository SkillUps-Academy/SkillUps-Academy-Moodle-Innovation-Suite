# Seguridad

Usa los [avisos privados del repositorio](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/security/advisories/new) cuando estén habilitados. Incluye versión, contexto, capacidades y datos de prueba sintéticos.

Las mutaciones usan Moodle Forms con sesskey y revisiones optimistas. El alcance se valida al resolver la audiencia, aprobar y enviar. Los errores de entrega se guardan como códigos acotados. El plugin utiliza Moodle Messaging para el correo y mantiene los conectores externos desactivados hasta que un administrador autoriza una clase instalada.
