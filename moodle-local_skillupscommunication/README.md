# SkillUps Communication Center

- **Componente** `local_skillupscommunication`
- **Edición** Community · SkillUps Moodle Innovation Suite
- **Versión** 0.9.0-beta.1
- **Idiomas** español e inglés
- **Moodle verificado** 5.0.12 y 5.3.1

Centro institucional de comunicaciones para Moodle con plantillas, segmentación, vista previa, aprobación y seguimiento por destinatario. La aprobación congela la audiencia y habilita la distribución programada a través de Moodle, con reintentos limitados e historial de operaciones.

1. Descarga el [ZIP instalable](../releases/skillupscommunication/skillupscommunication-0.9.0-beta.1.zip).
2. Instálalo desde **Administración del sitio → Plugins → Instalar plugins**.
3. Delega las capacidades de consulta, redacción, aprobación y configuración en los ámbitos Moodle correspondientes.
4. Redacta, previsualiza y envía el borrador a revisión. Confirma la aprobación para ponerlo en cola.

## English listing

### Short description

Plan, approve, schedule and track institutional communications within Moodle.

### Full description

SkillUps Communication Center supports scoped audiences, reusable templates, stable recipient previews, approval, scheduled dispatch and an auditable recipient ledger. It uses Moodle Messaging and Adhoc Tasks. Confirmed delivery is shown when an approved connector can provide reliable evidence. The plugin has no proprietary service dependency.

GPL v3 o posterior. SkillUps Academy mantiene este componente de forma independiente.
