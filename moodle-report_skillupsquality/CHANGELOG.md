# Registro de cambios

## 0.9.0-beta.1

- Catálogo institucional bilingüe de 12 reglas con separación entre evidencias comprobables y recomendaciones de diseño.
- Auditorías por curso, categoría y lista mediante tareas Adhoc con bloqueo, deduplicación, controles de permisos y recuperación de trabajos interrumpidos.
- Puntuación, comparación de revisiones, detalle de evidencias, planes de corrección y verificación con auditorías posteriores.
- Exportación CSV Community y Excel con autorización firmada. Aplicación local de retención y Privacy API de Moodle.
