**Short description**

Inspect Moodle course configuration, explain quality findings and track corrective plans.

**Full description**

SkillUps Course Quality Inspector audits courses, categories and selected batches. The configurable catalog covers course structure, dates, visibility, completion, grade ranges, rubrics and locally verifiable links and files. Findings separate verified issues from instructional design recommendations. Versioned summaries and corrective plans help authorized staff measure progress. Community includes the CSV export and operates without an external service.

The distribution ZIP contains the `skillupsquality` directory with `version.php` at its root. English is the canonical string set and Spanish is included for the suite. The Marketplace submission uses the provider portal for the archive, compatibility details, installation guide, screenshots and automated checks. The submission remains a draft.
