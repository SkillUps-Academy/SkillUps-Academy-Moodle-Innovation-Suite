# Contribuir

Abre un [issue](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/issues) para cambios funcionales. Usa datos sintéticos y sigue Moodle Coding Style. Mantén las cadenas canónicas en `lang/en` y la traducción distribuida en `lang/es` alineadas. Las operaciones nativas sobre los datos se ejecutan únicamente con las herramientas autorizadas de Moodle.

Inicializa PHPUnit en Moodle. Desde la raíz de la instalación ejecuta `vendor/bin/phpunit --testsuite local_skillupsprivacy_testsuite`. Para ver las instrucciones de Behat y la matriz de versiones, consulta [validación](docs/validation.md).
