## Short English description

Build, publish and monitor no-code Moodle workflows using a visual canvas, native actions and human approvals.

## Full English description

SkillUps Flow Automation lets authorized administrators design workflows with a visual editor, Moodle events, one-time or recurring schedules, conditional routes, notifications and approval gates. Revisions are published explicitly, and durable asynchronous executions retain transition history. The plugin provides JSON templates, a run dashboard, bilingual controls and privacy integration. The Community edition works independently. Optional signed entitlements enable aggregate CSV exports. SkillUps Academy is an independent provider.
