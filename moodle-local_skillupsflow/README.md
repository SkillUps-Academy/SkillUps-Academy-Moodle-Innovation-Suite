# SkillUps Flow Automation

Constructor visual de procesos para Moodle. Diseña, publica y supervisa flujos con eventos de Moodle, horarios, condiciones, acciones, esperas y aprobaciones. Community opera íntegramente en Moodle.

- Componente `local_skillupsflow`.
- Versión `0.9.0-beta.1`.
- Idiomas inglés y español.
- GPL-3.0-or-later. SkillUps Academy es un proveedor independiente de Moodle.
