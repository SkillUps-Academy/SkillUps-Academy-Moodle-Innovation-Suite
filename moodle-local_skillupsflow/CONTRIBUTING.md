# Contribuir

Presenta cambios mediante una rama `feature/*`, `bugfix/*` o `release/*`. Conserva inglés como fuente canónica y actualiza la traducción española. El código reside en la raíz de este subdirectorio dentro de la suite.

Ejecuta la suite `local_skillupsflow_testsuite`, Behat con `@local_skillupsflow`, Moodle CodeSniffer y el instalador ZIP. Para cambios en JavaScript utiliza el proceso AMD de Moodle y conserva el archivo compilado en `amd/build`. Verifica autorización y comportamiento de reanudación cuando cambies el motor o sus operaciones.
