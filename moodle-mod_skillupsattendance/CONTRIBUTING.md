# Contribuir

Usa datos sintéticos y sigue Moodle Coding Style. Mantén las cadenas de inglés como fuente canónica y conserva su paridad con español. Usa las APIs públicas de Moodle en cambios de archivos, calendario y calificaciones. Ejecuta las pruebas de alcance en más de un motor antes de modificar las consultas.
