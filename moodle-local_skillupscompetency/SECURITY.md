# Seguridad y privacidad

El plugin combina las capacidades propias con los permisos nativos de competencias, la matrícula y los grupos separados. Revalida el contexto antes de leer una evaluación, aplicar una decisión y entregar un archivo. Enlaces de evidencia requieren sesión autorizada y fuerzan descarga. Las propuestas y decisiones se guardan con un bloqueo Moodle. La aprobación rechaza propuestas con una escala o nivel base desactualizado.

Las evidencias aceptan PDF, DOCX, PNG y JPG. El límite es de tres archivos de hasta 5 MiB por propuesta, sujeto a Moodle. Configura las políticas de conservación y antivirus del sitio para los documentos académicos. Los CSV están sujetos al mismo alcance de autorización que los paneles y neutralizan prefijos de fórmulas.

La Privacy API descubre estudiantes, autores y revisores bajo el contexto del curso. Una eliminación aprobada de un estudiante retira su historial y sus archivos del plugin. Una eliminación de un autor o revisor desvincula sus datos y retira el contenido correspondiente. Los niveles y evidencias nativos publicados siguen el proveedor de privacidad de Moodle Core.

Comunica problemas mediante el [canal de seguridad del repositorio](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/security/advisories/new).
