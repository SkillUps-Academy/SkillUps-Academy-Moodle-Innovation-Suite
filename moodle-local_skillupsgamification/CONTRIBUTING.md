# Contributing

Use Moodle 5.3 as the reference and check the native API behavior on the supported branches. Run Moodle CodeSniffer, component PHPUnit and Behat. Keep English and Spanish keys aligned. Use synthetic users, activities and rewards in demonstrations.

Preserve the unique award and redemption identities. Add regression coverage before changing evidence verification, eligibility, team attribution or stock. Do not use live course records to reproduce a report. Report issues through the [suite tracker](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/issues) and see [SECURITY.md](SECURITY.md) for private reports.
