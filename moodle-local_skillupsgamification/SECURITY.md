# Security

Report vulnerabilities privately to the SkillUps Academy maintainers through the suite's GitHub repository where private reporting is available. Use synthetic progress and completion evidence in public issues.

Awards verify Moodle source identity and timestamp, active enrollment, earned-point capability, settings and limits. The application performs no native grade or enrollment updates. Session tokens protect configuration, self-service claims and ranking consent. A course lock and unique storage keys protect award and redemption races. Moodle owns the job execution and retry schedule.

Rankings start disabled and show aliases only after course enablement and individual opt-in. Separate groups restrict learner rankings. Team aggregates omit teams with fewer than three eligible consenting contributors. The optional integration is restricted to the documented locally installed provider class. The plugin sends no records to external services.
