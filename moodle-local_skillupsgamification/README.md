## English

Install the ZIP from Moodle site administration, then open **Course → More → SkillUps Gamification Pro → Manage gamification**. Enable the course and define rules for verified completion. Community includes all progress, challenges, rewards and private rankings. An optional signed entitlement unlocks aggregate CSV export. No external service or additional library is required.
