# SkillUps Smart Enrollment Manager

**`tool_skillupsenrollment`** · Herramienta de administración Moodle · GPL-3.0-or-later

Prepara matriculaciones, asignaciones de roles y cambios de estado a partir de CSV, XLSX o un registro individual. La simulación muestra el método, el estado previo y el resultado esperado. Los lotes confirmados se ejecutan mediante las tareas nativas de Moodle. Las acciones quedan en un historial consultable por curso, usuario o lote.

## English

Install the ZIP through **Site administration → Plugins → Install plugins**. Open **Site administration → Courses → SkillUps Smart Enrollment Manager** and run a simulation. Confirm valid rows to schedule their native Moodle tasks. Community includes CSV/XLSX import, CSV reports and the optional local Course Factory contract.
