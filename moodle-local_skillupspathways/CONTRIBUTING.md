# Contribuciones

Usa fixtures generados por Moodle para reproducir incidencias y registra la versión de Moodle y el motor de base de datos. Ejecuta el análisis de estilo y las pruebas reproducibles de [validación](docs/validation.md). Si cambias el editor, compila y entrega su módulo RequireJS desde el código fuente. Mantén los catálogos en inglés y español en el mismo cambio.
