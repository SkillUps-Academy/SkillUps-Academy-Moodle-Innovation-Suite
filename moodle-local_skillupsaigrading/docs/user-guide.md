# Guía docente

1. En el curso, abre **SkillUps AI Grading Assistant** y elige una tarea individual. La tarea debe usar una rúbrica publicada y mostrar las identidades.
2. Abre un participante con una entrega enviada. Selecciona texto en línea o un documento y pulsa **Preparar evidencias**. Elige fragmentos relevantes y elimina pasajes sensibles. Puedes seleccionar varias líneas extraídas de una misma fuente.
3. Crea una hoja local sin IA o selecciona un proveedor habilitado. Para IA revisa también la rúbrica, autoriza el envío y actualiza el estado cuando cron procese la cola.
4. Revisa las citas, justificaciones, posibles omisiones y niveles. Las recomendaciones quedan marcadas como inciertas si el nivel está fuera de la rúbrica, faltan citas verificables o el modelo indica evidencia insuficiente.
5. Edita el borrador, aprueba o rechaza la revisión. El historial conserva las acciones y el asistente exige una revisión nueva para aprobar cuando cambia el intento, la fuente o la rúbrica. Usa **Abrir el calificador de Moodle** para registrar tu evaluación formal.
6. Para IA con porcentaje completo, **Registrar comparación de nota** captura la nota numérica del mismo intento cuando coincide con la nota final, está libre de sobrescrituras y la tarea admite la comparación. La diferencia está en puntos porcentuales. En el panel, la diferencia absoluta media describe la concordancia de las comparaciones registradas. Las rúbricas con criterios inciertos conservan sugerencias parciales.

En una actividad con grupos separados, cambia de grupo con el selector nativo cuando cuentes con acceso. Se conservan las decisiones mientras la revisión se halle dentro del período de retención.
