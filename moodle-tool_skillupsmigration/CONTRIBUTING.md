# Contribuciones

Abre incidencias en [Issues de la suite](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/issues) con instalaciones desechables y datos sintéticos. Indica versión de ambas instancias, tipo de actividad y fase. Nunca adjuntes tokens ni respaldos con datos institucionales.

Incluye una regresión concreta si tocas autorización, validación del archivo, ejecución nativa o reanudación.
