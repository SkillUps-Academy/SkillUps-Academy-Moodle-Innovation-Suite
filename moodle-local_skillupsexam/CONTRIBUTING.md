# Contribuciones

Reporta errores funcionales en [Issues de la suite](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/issues). Usa datos sintéticos y detalla la versión de Moodle, PHP, el motor de base de datos y el ámbito de las capacidades. Para cambios de integración nativa, incluye una prueba real del módulo correspondiente.

Sigue las convenciones de Moodle para PHP, XMLDB y Moodle Forms. Las cadenas se mantienen en inglés y español. Ejecuta las pruebas en un sitio de desarrollo con configuración PHPUnit independiente antes de enviar cambios.
