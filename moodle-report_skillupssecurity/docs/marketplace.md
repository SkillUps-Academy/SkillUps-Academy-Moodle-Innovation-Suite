## Short description

Review Moodle privileges, administrative events and security configuration with scoped findings, evidence exports and case review.

## Full description

Security Center inventories selected high-impact Moodle permissions, reviews sensitive settings and flags inactive accounts and unusual role assignments. It records authorized report access, supports retention and sends generic notifications through Moodle messaging. Control coverage is explicit and the report distinguishes observations, review priorities and policy recommendations.

El ZIP contiene `skillupssecurity/version.php`. El código se publica dentro del monorepositorio. Confirma el flujo oficial de traducciones y revisión al presentar el paquete.
