# SkillUps Content Repository

- **Componente** `local_skillupsrepository`
- **Edición** Community · SkillUps Moodle Innovation Suite
- **Versión** 0.9.0-beta.1
- **Idiomas** español e inglés
- **Moodle verificado** 5.0.12 y 5.3.1

Biblioteca institucional de materiales Moodle con clasificación académica, búsqueda, revisión y versiones. Los docentes autorizados pueden copiar una versión aprobada a su curso como actividad nativa **Archivo** o **URL**. El registro identifica la versión entregada y la actividad que se creó.

## Instalación y uso

1. Descarga el [ZIP instalable](../releases/skillupsrepository/skillupsrepository-0.9.0-beta.1.zip) desde la carpeta de versiones.
2. Instálalo en **Administración del sitio → Plugins → Instalar plugins**.
3. Asigna capacidades de biblioteca a los roles en las categorías correspondientes.
4. Añade un archivo o enlace. Envía la versión a revisión y apruébala antes de compartirla.

## English listing

### Short description

Organize, review, version and reuse institutional teaching resources in Moodle.

### Full description

SkillUps Content Repository provides a category-scoped library with search facets, grid and list views, approved public or institutional sharing, private work, media previews, license metadata and operational audit history. Approved versions can be copied to native File and URL activities with version provenance. Uploaded files are managed and served through Moodle File API.

GPL v3 o posterior. SkillUps Academy desarrolla el componente de forma independiente. La instalación usa dependencias nativas de Moodle y PHP.
