# Contributing

Verify changes using PHP CodeSniffer with the Moodle rules, the component PHPUnit suite and the Behat scenario. Use Moodle 5.3 as the primary reference and test any API change across supported releases. Keep English language strings canonical and Spanish keys in parity.

Use synthetic requesters, staff and files. Test authorization for detail, list, attachment and export together after changing an access rule. For security reports follow [SECURITY.md](SECURITY.md). Use the [suite issue tracker](https://github.com/SkillUps-Academy/SkillUps-Academy-Moodle-Innovation-Suite/issues) for other defects.
