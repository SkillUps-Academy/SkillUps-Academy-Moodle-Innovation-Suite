## English

Install the ZIP in Moodle site administration, assign the system support roles and configure the business calendar. The primary **SkillUps Helpdesk** link opens the requester portal or authorized staff queue. Community includes the complete ticket workflow, knowledge base, satisfaction surveys and CSV reports. A signed offline entitlement adds JSON export. There are no third-party library dependencies.
