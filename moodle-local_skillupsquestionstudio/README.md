# SkillUps Question Studio

Generador de preguntas y evaluaciones para Moodle. Trabaja con documentos y borradores privados del curso, con revisión docente antes del banco de preguntas.

- Componente `local_skillupsquestionstudio`.
- Versión `0.9.0-beta.1`.
- Inglés y español.
- GPL-3.0-or-later. SkillUps Academy es un proveedor independiente de Moodle.
