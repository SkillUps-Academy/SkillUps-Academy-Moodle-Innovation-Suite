# Guía docente de Question Studio

1. Crea un proyecto desde la navegación del curso. Docentes autorizados del curso pueden colaborar en él.
2. Carga un PDF, DOCX, PPTX o TXT. Actualiza el proyecto cuando el cron haya procesado el archivo. Usa **Ver texto fuente** para comprobar lo extraído.
3. Para un borrador local, elige tipo, cantidad, dificultad, nivel Bloom, unidad y, si Moodle las tiene configuradas, una competencia vinculada al curso. Los glosarios con formato `concepto: definición` dan resultados más claros. Con tres o más conceptos distintos se pueden proponer distractores y emparejamientos. La cantidad solicitada es un máximo.
4. Abre una pregunta del gestor y contrasta el texto, las respuestas y la clasificación. El editor admite selección múltiple con una correcta, verdadero/falso, emparejamiento, respuestas cortas exactas y ensayo con guía de calificación. En emparejamiento, escribe las dos listas en el mismo orden. La dificultad y Bloom del generador local son metadatos que requieren confirmación docente.
5. Guarda una revisión y usa **Aprobar esta revisión** cuando sea adecuada. Guardar cambios o volver a borrador revoca esa aprobación. Las revisiones anteriores pueden consultarse desde el historial.
6. Crea dos o más versiones de evaluación con los nombres deseados. Cada versión conserva su selección y el orden de sus opciones. Desde la vista previa puedes mostrar la clave, descargar XML o importar a una categoría del curso. Si una revisión pierde aprobación, crea una variante nueva.
7. Abre el banco en Moodle y selecciona las preguntas para agregarlas a un cuestionario. Studio genera la evaluación y publica sus preguntas. La configuración de la actividad, fechas, calificación y sesiones se administra en el cuestionario de Moodle.

El almacenamiento rechaza duplicados exactos normalizados dentro de un proyecto. El editor también avisa de posibles duplicados léxicos para revisión. La importación evita crear dos veces la misma revisión en una categoría. Una revisión nueva publicada después de editar es una nueva entrada en el banco.
