## Short English description

Turn course documents into teacher-reviewed Moodle questions, alternative assessment versions and bank-ready Moodle XML.

## Full English description

SkillUps Question Studio provides course projects for PDF, DOCX, PPTX and plain text, local draft generation and optional Moodle AI generation. Teachers can edit five native question types, classify them, detect duplicates and approve exact revisions before previewing assessment variants, downloading Moodle XML or importing into an authorized course question bank. Question Studio uses Moodle's native question importer and is maintained independently by SkillUps Academy.
